2. Теоретическая часть
2.1. Технология MPI
MPI (Message Passing Interface) — это стандарт интерфейса для обмена сообщениями между процессами в параллельных вычислительных системах. В отличие от OpenMP, который работает с потоками в общей памяти, MPI использует несколько независимых процессов с собственной памятью. Процессы обмениваются данными через сообщения.

Основные характеристики MPI:
Модель с распределённой памятью — каждый процесс имеет свою собственную память
Явная коммуникация — процессы отправляют и получают данные через специальные функции
Масштабируемость — может работать на нескольких компьютерах в сети
Поддержка различных языков — C, C++, Fortran, Python

2.2. Особенности реализации умножения матриц в MPI
При умножении матриц в MPI используется подход с распределением данных:
Процесс 0 читает исходные матрицы из файлов
Матрица B рассылается всем процессам широковещательной рассылкой (MPI_Bcast)
Матрица A разбивается на горизонтальные полосы (наборы строк), каждая полоса отправляется своему процессу (MPI_Scatterv)
Каждый процесс умножает свою часть матрицы A на всю матрицу B
Результаты собираются на процессе 0 (MPI_Gatherv)

4. Анализ сравнения
MPI быстрее OpenMP для всех размеров матриц:

Для матрицы 400×400 MPI в 2.1 раза быстрее на 2 процессах
Для матрицы 800×800 MPI в 1.9 раза быстрее на 2 процессах
Для матрицы 1200×1200 MPI в 2.0 раза быстрее на 2 процессах
Для матрицы 1600×1600 MPI в 1.9 раза быстрее на 2 процессах

Причины преимущества MPI:
Отсутствие накладных расходов на синхронизацию кэша
Более эффективное использование памяти
Линейное масштабирование на небольших количествах процессов
